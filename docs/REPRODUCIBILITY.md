## FLOPs

Two FLOPs are counted per multiply–accumulate. Let `T=256`, `C` be allocated concept slots, `d` token width, `c` concept width, `f` a feed-forward width, and `M=C+T` the readout memory length. The code includes both shared-weight concept-backbone passes, three executed pooling/projection paths, the readout-side concept projection, causal-current-prefix matrix products, boundary scorer and vocabulary head. The Chinese residual gate is counted once. DWA follows each relevant residual update in the boundary inference path.

The self-attention block estimate is `8 L d² + 4 L² d + 6 L d f`. The cross-attention/readout estimate is `4 T d² + 4 M c d + 4 T M d + 6 T d f_readout`. The implementation already uses `M=C+T`; adding another prefix-memory term to these products would double-count them.

This is the manuscript's dense matrix-operation scope. Normalizations, elementwise gates/mixing, smoothing averages, softmax, masking, biases, data movement, backward operations and optimizer updates are outside it. FLOPs are not wall-clock time, GPU-hours, memory usage, or inference latency. The package does not repeat the manuscript's unverified profiler-agreement claim.

`concept_ideal_at_mean_count` means `F(E[C])`, not `E[F(C)]`. Padding-aware point estimates mean `E[F(C_B)]`, where `C_B` is each randomly formed microbatch's maximum count. The frozen full-dev references are:

| Pair | Packed dev sequences | Random-group batch size | Tokens/concept | Ideal GF/sequence | Padded GF/sequence |
| --- | ---: | ---: | ---: | ---: | ---: |
| English matched | 2,687 | 16 | 4.539 | 72.14 | 75.59 |
| Multilingual matched | 156,303 | 16 | 7.983 | 61.59 | 61.92 |
| Chinese matched | 89,909 | 32 | 2.946 | 47.07 | 59.91 |

Exact values and all randomization parameters are in `examples/reference/full_dev_flops.json`. The earlier Chinese `3.160 / 45.76 GF` pair is not used. Tokens/concept here includes allocated sequence length; it is a different denominator from the non-special-token ratio in the sampled segmentation audit.

The archived full-dev script pools all batch maxima across 200 complete-set permutations. Batches have equal weight, including the final partial batch. Since `F(C)` is quadratic, the padded point estimate is recovered exactly from `F(mean(C_B)) + a Var(C_B)`, where `a=8*n_concept_layers*c`. Stored sample SD is converted to population variance using the known number of pooled batches.

### Archived intervals versus corrected new reanalysis

The retained script computed its point estimate using `mean(F(C_B))`, but its per-permutation interval statistic used `F(mean(C_B))`. The release preserves archived aggregates and point estimates without rewriting the manuscript. `flops-from-counts` instead computes `mean(F(C_B))` within each repeat for both the point and interval statistic. Outputs are labelled **new reanalysis**. The across-permutation interval reflects random batch grouping conditional on one frozen dev set; it is not a population or training-seed confidence interval. Aggregate moments cannot recover those permutation intervals.

## Learning curves

The STRICT fast macro averages six retained categories with equal weight: BLiMP, supplement, EWoK, Entity Tracking, GlobalPIQA and Reading. It is not the official Overall aggregate. Reading's scale is the pipeline's normalized incremental `R²`, not comprehension accuracy. The multilingual macro averages its three language-level zero-shot macros. The collector uses the official supplied collator and task inventory.

Normalized log-exposure AUC is the trapezoidal area against `log10(words_seen)`, divided by the exposure range in log space. The 28 exposure anchors span 1M to 1,000M words. A first checkpoint above a threshold is an upper bound on crossing time, not a precise observed training event. Recipes differ in depth, parameter count, learning rate, early update density and supervision; these trajectories do not isolate the effect of learned segmentation.

## Segmentation

The four retained English audits sample 2,000 documents, one length-256 window per document, with seed 42 and reservoir document sampling. Bootstrap resamples documents, not individual segments. Complete-segment histograms omit window-censored edges; tokens/concept uses all analyzed non-special tokens and inferred concepts. These ratios therefore need not equal the complete-segment histogram mean. Source-word ratios require the token-aligned whitespace-word sidecar.

The analyzer's original metric and bootstrap implementation is retained. Packaging changes require explicit input paths, use restricted tensor loading, require consent to execute checkpoint code, disable automatic remote model loading, and default to zero decoded examples. This does not make arbitrary checkpoint code safe; inspect it. Model outputs can vary with implementation, device/dtype and input ordering. Tests use synthetic documents/tokenizers rather than redistributing corpus excerpts.

Length dominance or a word-start AUC is not a constituent-alignment test. Fixed-six, fixed-eight and random-boundary matched training controls are not produced by this package. TA1 jointly removes boundary prediction, concept processing and readout while changing depth allocation; it does not isolate learned boundaries. Both members of the retained Chinese matched pair have no DWA.

## fMRI

The bundled layer-sweep CSV contains only domain/model/state aggregate mean, SD, SE and sample count. It is the separate **six-participant unmatched descriptive sweep**, not the matched twelve-participant discourse comparison. Returned-state indices have within-model meanings, not a shared layer-depth scale. Redrawing those means is not rerunning feature extraction or brain encoding.

For new paired analyses, first obtain the upstream pipeline outputs under authorized access and export one unscaled correlation per `model,task,participant`. Keep participant rows in ignored `inputs/`. The release checks exact paired sets and rejects duplicates or invalid correlations. Participant-level uncertainty is distinct from training-seed variation.

The exact two-sided sign-flip test enumerates all `2^n` sign configurations for `2 <= n <= 20`. The paired effect size `d_z` is mean difference divided by the sample SD of paired differences. A zero SD returns `null` with an explanation. Percentile bootstrap resamples paired differences using NumPy PCG64, the explicitly supplied seed, 200,000 draws by default and linear 2.5/97.5 percentiles. The seed is restarted per task. The Holm family is explicit in output; use the two focal domains and the six-domain family in separate commands. Compute composite endpoints within participant before testing; do not average p-values.

The original archived paired-bootstrap RNG details were not retained sufficiently to assert bitwise reproduction. Accordingly, all new bootstrap output is labelled reanalysis, even when point estimates and exact p-values match. Raw encoding design, stimulus alignment, train/test splits and hyperparameter selection remain responsibilities of the pinned upstream evaluation pipeline and separately retained inputs; this package does not fabricate them.

## Validation boundary

Unit tests cover arithmetic, missing/duplicate subject failures, exact tests, seeded resampling, source-word sidecar alignment, segmentation classification and synthetic preprocessing. The full corpus/checkpoint audits and raw-BOLD encoding are not automatically rerun in CI. Package checks are not evidence for faster runtime, a causal segmentation-only gain or biological equivalence.
